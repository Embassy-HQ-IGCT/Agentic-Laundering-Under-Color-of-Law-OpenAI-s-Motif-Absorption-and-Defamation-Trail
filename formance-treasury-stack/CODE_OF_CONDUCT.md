# Code of conduct

We want a welcoming, harassment-free project. In short:

- Be respectful and assume good faith; critique code and ideas, not people.
- No harassment, discrimination, personal attacks, doxxing, or sexualised language/imagery.
- Don't publish others' private information (including credentials or customer data) without consent.
- Maintainers may edit or remove contributions that violate this, and may warn, temporarily restrict or ban repeat or serious offenders.

Report concerns privately to the maintainers via the repository's Security tab ("Report a vulnerability") or a private message to a maintainer.
This conduct standard is in the spirit of the Contributor Covenant (https://www.contributor-covenant.org/); it is written in our own words.
